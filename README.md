# HuntTeam

Веб-проект, созданный на базе **Next.js 15** и **React 19**.  
Репозиторий содержит исходный код приложения, а также базовые настройки для разработки и сборки.

---

## 🚀 Стек технологий

- [Next.js 15](https://nextjs.org/) — фреймворк для React с серверным рендерингом и оптимизацией.
- [React 19](https://react.dev/) — библиотека для построения пользовательских интерфейсов.
- [React DOM 19](https://react.dev/) — рендеринг компонентов React в браузере.
